**VCS** - инструмент для отслеживания изменений в файлах. Нужна чтобы не потерять историю и работать в команде. Используется в разработке, документации, дизайне.

**Репозиторий** - хранилище проекта со всеми файлами и историей изменений. Бывает локальным и удалённым.

**Коммит** - снимок состояния файлов в определённый момент. Осмысленное сообщение нужно чтобы понимать что именно менялось, глядя на историю.

**Public** - виден всем, для открытых и учебных проектов. Private - только тебе, для личного и коммерческого кода.

**Ветка** - параллельная версия проекта для работы без риска сломать основную. Текущую ветку видно в выпадающем списке вверху слева на странице репозитория.
